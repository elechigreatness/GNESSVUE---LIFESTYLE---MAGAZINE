 GNESSVUE — LIFESTYLE — MAGAZINE

A premium multi-niche lifestyle magazine covering Cooking, Tech, Travel & Fitness with modern magazine UI.

Live Demo: https://elechigreatness.github.io/GNESSVUE---LIFESTYLE---MAGAZINE/

 ✨ What Inside

COOKING - Recipes, food hacks, quick meals
TECH - VR, gadgets, AI tools
TRAVEL - Destinations, budget trips, 2024 guides  
FITNESS - Workouts, fat burn, arm training

 🎨 Features
- fixed header with GNESSVUE logo
- Full-width hero for each category
- Card grid with images + CTA buttons
- Pink accent + clean typography
- 100% responsive - works on phone & laptop

 🛠️ Built With
- HTML5
- CSS3 (Flexbox / Grid)
- Vanilla JS for menu

 🚀 How To Use / Run
1. Clone repo: `git clone https://github.com/elechigreatness/GNESSVUE---LIFESTYLE---MAGAZINE.git`
2. Open `index.html` in browser or use Live Server (port 5500)
3. To make live: GitHub Settings > Pages > Deploy from main branch
